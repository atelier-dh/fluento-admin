4. Question review

Menampilkan isi tabel question_extraction_candidates apa adanya (semua ujian, semua status). Gunakan ini untuk memeriksa, approve, atau reject soal.

5. Backend check

Memeriksa login admin, 19 tabel utama, dan 2 Edge Function. Catatan: angka 0 bisa berarti tabel kosong atau terblokir RLS.

6. Import question bank (JSON)

Pilih fluento_question_bank.json. Pemetaan kolom sudah disesuaikan dengan skema question_extraction_candidates milikmu, jadi tidak perlu mencocokkan manual. Semua soal masuk sebagai needs_review.

7. Publishing

Menerbitkan soal berstatus approved menjadi Course → Unit → Package → Lesson → Question (lengkap dengan pilihan dan kunci jawaban), langsung tersedia untuk siswa. Soal writing masuk ke writing_prompts. Aman dijalankan berulang: soal yang sudah terbit dilewati.
